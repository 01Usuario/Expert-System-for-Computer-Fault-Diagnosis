# Sistema Experto para Diagnóstico de Fallas de Computadora

Sistema experto en Prolog (SWI-Prolog) que, a partir de los síntomas
reportados por el usuario, infiere las fallas más probables de una PC
y sugiere un plan de reparación.

## Ejecución

    swipl diagnostico_pc.pl
    ?- iniciar.

(Estado: en desarrollo; la ejecución completa estará disponible al
terminar los commits de las etapas siguientes.)
